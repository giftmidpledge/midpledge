4. Действия владельца

Транзакции доступны только если подключённый кошелёк совпадает с owner пула. Перед подтверждением внимательно проверьте адрес получателя.
RescueNft вернёт NFT из детерминированного хранилища пула только при status = 0. Если займ активен, контракт должен отклонить действие.
Liquidate должен отправляться напрямую в escrow и сработает только при активном займе, от адреса owner, после dueAt + grace period. Комиссия сети оплачивается подключённым кошельком.
